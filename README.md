# Aldeano Phora (Fabric)

Mod de Minecraft 1.20.1 para Fabric que añade al Aldeano Phora, sus intercambios y objetos asociados.

## Características

- Aldeano Phora animado y sus interfaces de comercio.
- Tablet para configurar los objetos de costo y recompensa de los intercambios.
- Llave de cobre consumible para activar, reiniciar y apagar al Phora.
- Dilitio, recursos gráficos y modelos editables de Blockbench en `blockbench/`.

## Compilar

Requiere Java 17. Desde la carpeta del proyecto ejecuta:

```bash
./gradlew build
```

En Windows también puedes usar `gradlew.bat build`. El mod compilado queda en `build/libs/aldeanoforaflut-1.0.0.jar`.

Para iniciar el cliente de desarrollo, ejecuta `./gradlew runClient`.
